STEP 1: VERIFY YOU HAVE KICAD 6.0+
═══════════════════════════════════════════════════════════════════════════════

Windows: 
  Open KiCAD → Help → About
  Check version is 6.0 or higher

Mac/Linux:
  Open terminal, type: python3 --version
  Should show: Python 3.9+

If you don't have it:
  → Download from https://www.kicad.org/download

STEP 4: MODIFY ONE LINE IN EACH SCRIPT
═══════════════════════════════════════════════════════════════════════════════

In EVERY script file, find this line:
  PROJECT_DIR = "C:/Users/YourName/my_project/kicad_project"

Replace with YOUR path:
  Windows example:
    PROJECT_DIR = "C:/Users/Bola/photonic_project/kicad_project"
  
  Mac example:
    PROJECT_DIR = "/Users/bola/photonic_project/kicad_project"
  
  Linux example:
    PROJECT_DIR = "/home/bola/photonic_project/kicad_project"

That's it! Just update that one line in each file.

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Problem: "ModuleNotFoundError: pcbnew"
Solution: Use KiCAD's Python, not system Python
  Windows: Right-click → "Open KiCAD Command Prompt"
  Mac/Linux: Try: python3 script.py (usually works)

Problem: "PROJECT_DIR not found"
Solution: 
  1. Check path is correct
  2. Use full path: C:/Users/Name/... (not relative paths)
  3. Use forward slashes / (even on Windows)

Problem: "Component U1 not found"
Solution:
  • Ignore this for now
  • It means you haven't added components from schematic yet
  • Later: In KiCAD Schematic → Update PCB
