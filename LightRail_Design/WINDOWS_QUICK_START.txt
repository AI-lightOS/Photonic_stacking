STEP 1: INSTALL KICAD
═════════════════════════════════════════════════════════════════════════════════

1. Download KiCAD:
   https://www.kicad.org/download/

2. Click "Windows Installer" (64-bit recommended)

3. Run the installer:
   - Click through with default settings
   - Make sure "Add KiCAD to PATH" is checked
   - Install to: C:\Program Files\KiCAD\

4. Verify installation:
   - Open Command Prompt (Windows + R, type "cmd")
   - Type: kicad --version
   - Should show: KiCAD 6.0.2 or higher

TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════════

Problem: "python: command not found"
Solution:
  1. Open Command Prompt as Administrator
     (Windows + X, select "Command Prompt (Admin)")
  2. Reinstall Python (download from python.org)
  3. Make SURE to check "Add Python to PATH"

Problem: "ModuleNotFoundError: No module named 'pcbnew'"
Solution:
  1. Verify KiCAD installed: kicad --version
  2. If not found, reinstall KiCAD
  3. Make sure to add KiCAD to PATH during install

Problem: "File not found" or "Permission denied"
Solution:
  1. Run Command Prompt as Administrator
  2. Verify folder path: C:\LightRail_AI_NCE\ exists
  3. Check Windows Defender isn't blocking file access

Problem: "Script runs but files not created"
Solution:
  1. Check folder permissions:
     Right-click C:\LightRail_AI_NCE → Properties → Security
  2. Make sure it's readable/writable
  3. Try running as Administrator
