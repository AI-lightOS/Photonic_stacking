DESIGN DECISIONS MADE:
═════════════════════════════════════════════════════════════════════════════════

1. PHOTODIODE SPECIFICATIONS (Assumed)
   ├─ Type: Integrated Ge on silicon photonics PIC
   ├─ Wavelength: 1550 nm (telecom band)
   ├─ Responsivity: 0.8 A/W
   ├─ Capacitance: 50 pF (parallel to junction)
   ├─ Dark current: 1 µA (typical for Ge)
   └─ Output: Current source (nanoamps to microamps range)

2. TIA DESIGN (per channel)
   ├─ Op-Amp: OPA2356 (1.4 GHz GBW, ultra-low input current)
   ├─ Feedback resistor: 10 MΩ (for high impedance)
   ├─ Feedback capacitor: 50 pF (stability compensation)
   ├─ Transimpedance gain: Rf = 10 MΩ → 10 MV/A
   ├─ Output swing: 0 to +3.3V (single supply)
   ├─ Output bandwidth: ~160 MHz (-3dB with Cf compensation)
   └─ Estimated noise: ~4 pA/√Hz (very low)

3. PHASE SHIFTER CONTROL
   ├─ Type: Thermo-optic (heater resistor on PIC)
   ├─ Tuning voltage: 0 to +3.3V (from DAC)
   ├─ Heater resistance: ~1 kΩ (on chip)
   ├─ Power per shifter: ~50 mW typical
   ├─ Response time: ~10 ms (thermo-optic is slow, but mature)
   ├─ Control accuracy: 12-bit DAC (0.8 mV resolution)
   └─ Optional: Temperature feedback via TMP36 sensor

4. COMPARATOR THRESHOLDS
   ├─ Comparator: LM393 (dual, open-collector output)
   ├─ Reference voltage: 1.65V (set by resistor divider from 3.3V)
   ├─ Threshold (for 1.65V ref): TIA output crosses 1.65V → spike
   ├─ Hysteresis: ~50 mV (optional, via feedback resistor)
   ├─ Spike output: Open-drain logic, 3.3V compatible
   └─ Pull-up: 10 kΩ to 3.3V

5. USB INTERFACE
   ├─ Controller: FT2232H (dual-channel USB bridge)
   ├─ Interface 1: SPI (control DAC for phase shifters)
   ├─ Interface 2: UART or Parallel (read spike data from comparators)
   ├─ USB Type: USB 2.0 High-Speed (480 Mbps capable)
   ├─ Power: 5V from USB, 500mA max (or negotiate up to 3A with PD)
   └─ Host: Windows/Mac/Linux via standard USB FTDI drivers

6. POWER DISTRIBUTION
   ├─ Input: USB 5V
   ├─ Rail 1: +3.3V (analog supply for TIA/comparators/DAC)
   ├─ Rail 2: +5V (digital I/O, USB logic)
   ├─ Optional Rail 3: -5V (comparator negative rail for common-mode swing)
   ├─ Regulators: MCP1703 (3.3V, 500mA) + TPS54302 (optional -5V)
   └─ Filtering: LC filter on 3.3V rail (critical for analog noise)

CRITICAL COMPONENT NOTES
═════════════════════════════════════════════════════════════════════════════════

1. OPA2356 (TIA Op-Amp)
   • Why this part?
     - Ultra-low input current (1 pA typical)
     - 1.4 GHz gain-bandwidth product (fast response)
     - Available in dual package (saves PCB space)
   
   • Alternative (if unavailable):
     - LT6268 (Linear Tech) - similar specs, lower noise
     - AD8065 (Analog Devices) - good performance, easier to find
   
   • Critical design rule:
     - Input traces < 1mm long (parasitic capacitance adds noise)
     - Feedback network very close to op-amp pins
     - Ground plane under op-amp for shielding

2. AD5684 (12-bit DAC)
   • Configuration: Quad (1 DAC controls up to 4 phase shifters)
   • Interface: SPI (SCLK, MOSI, LDAC, CS)
   • You'll use 2 of these DACs total to control all 8 phase shifters
   
   • Connection:
     LDAC (Latch DAC) → tied to SPI_CS (synchronized update)
     MOSI (data) → FT2232H Ch A
     SCLK (clock) → FT2232H Ch A

3. FT2232H (USB Bridge)
   • Dual-channel design:
     Channel A: SPI for DAC control (write phase shifter values)
     Channel B: UART for spike data readout (read comparator outputs)
   
   • USB drivers:
     Windows: VCP (Virtual COM Port) - standard windows USB
     Mac/Linux: libftdi (open source, commonly available)
   
   • Typical command flow:
     1. Open USB device via FT2232H
     2. Configure SPI timing on Channel A
     3. Write 16-bit DAC command word
     4. Latch output (toggle LDAC)
     5. Read UART data on Channel B (spike events)

4. LM393 (Comparator)
   • Dual design (4 ICs → 8 comparators)
   • Open-collector output (needs pull-up to 3.3V)
   • Threshold voltage:
     - Set at 1.65V (mid-point of 3.3V rail)
     - Resistor divider: 10kΩ + 10kΩ
     - TIA output > 1.65V → Spike goes low (active-low output)
   
   • Optional hysteresis (prevent chatter):
     - Add 100kΩ feedback resistor from output to inverting input
     - Creates ~50 mV hysteresis

5. MCP1703 (3.3V LDO)
   • Why 3.3V specifically?
     - Standard for digital I/O (USB, SPI)
     - Op-amp single-supply operation (0V to 3.3V)
     - Comparator threshold (mid-rail biasing)
   
   • Noise specification:
     - < 60 µV RMS (critical for analog circuits)
     - Clean supply for TIA and DAC
   
   • Alternative (if MCP1703 unavailable):
     - TL7733 (Texas Instruments) - similar performance
     - AMS1117-3.3 (but slightly higher noise)
