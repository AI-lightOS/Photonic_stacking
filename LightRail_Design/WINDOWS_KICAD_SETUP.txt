WINDOWS INSTALLATION GUIDE
═════════════════════════════════════════════════════════════════════════════════

STEP 1: INSTALL KICAD ON WINDOWS
─────────────────────────────────

1. Download KiCAD from: https://www.kicad.org/download/

2. Download the Windows installer (.exe)
   Recommended: KiCAD 6.0 or 8.0 (stable releases)

3. Run the installer:
   - Click "Next" through all prompts
   - Install to default location: C:\Program Files\KiCAD\
   - Make sure "Add KiCAD to PATH" is checked
   - Complete installation

4. Verify installation by opening Command Prompt:
   
   kicad --version
   
   Should show: KiCAD 6.0.2 (or your version)

═════════════════════════════════════════════════════════════════════════════════
STEP 2: INSTALL PYTHON REQUIREMENTS
────────────────────────────────────

Open Command Prompt (Windows + R, type "cmd"):

1. Install required Python packages:

   pip install pyautogui pillow openpyxl

2. Verify installation:

   python --version
   python -m pip list | findstr pyautogui

TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════════

Problem: "python: command not found"
Solution:
  1. Open Command Prompt as Administrator (Windows + X, select "Command Prompt (Admin)")
  2. Reinstall Python with "Add Python to PATH" checked
  3. Or use full path: C:\Users\YourUsername\AppData\Local\Programs\Python\Python39\python.exe

Problem: "ModuleNotFoundError: No module named 'pcbnew'"
Solution:
  1. KiCAD must be installed BEFORE running scripts
  2. Verify KiCAD installation: kicad --version
  3. Reinstall KiCAD if needed (make sure PATH is set)

Problem: "Permission denied" when creating files
Solution:
  1. Run Command Prompt as Administrator
  2. Make sure C:\LightRail_AI_NCE\ folder is writable
  3. Check Windows Defender or antivirus isn't blocking access

Problem: "Script runs but files not created"
Solution:
  1. Check folder permissions: Right-click folder → Properties → Security
  2. Verify KiCAD was installed properly
  3. Try running Command Prompt as Administrator

Problem: "PCB file won't open in KiCAD"
Solution:
  1. Make sure KiCAD is installed (kicad --version)
  2. Try opening KiCAD first, then File → Open
  3. Check file isn't corrupted: File size should be > 1KB
