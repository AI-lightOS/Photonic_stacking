  run_lightrail.sh

──────────────────────

  bash /path/to/run_lightrail.sh

TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════════

Problem: "bash: run_lightrail.sh: No such file or directory"
Solution: Make sure you're in the correct directory
  cd ~/Downloads
  bash run_lightrail.sh

Problem: "KiCAD not found"
Solution: Install it first
  sudo apt update
  sudo apt install kicad

Problem: "Permission denied"
Solution: Make script executable
  chmod +x run_lightrail.sh
  bash run_lightrail.sh

Problem: "Python error"
Solution: Make sure KiCAD Python bindings are installed
  sudo apt install python3-kicad
