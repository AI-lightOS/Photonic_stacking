📖 HOW TO USE THESE FILES
════════════════════════════════════════════════════════════════════════════════

STEP 1: INSTALL KICAD (30 minutes)
────────────────────────────────────────────────────────────────────────────────
Download: https://www.kicad.org/download/
Install: Default settings (Windows, Mac, or Linux)
Launch: Open KiCAD application

STEP 2: READ QUICK START (15 minutes)
────────────────────────────────────────────────────────────────────────────────
File: README_QUICK_START.txt (you are reading this)
Actions:
  • Read sections: "QUICK START", "DESIGN SPECIFICATIONS"
  • Review "KEY DESIGN DECISIONS"
  • Skim "TOOLS & RESOURCES"

STEP 3: OPEN THE PROJECT (5 minutes)
────────────────────────────────────────────────────────────────────────────────
1. KiCAD main window: File → Open Project
2. Navigate to: LightRail_NCE_MVP.kicad_pro
3. Project opens showing schematic

STEP 4: REVIEW SCHEMATIC (1-2 hours)
────────────────────────────────────────────────────────────────────────────────
1. Double-click: LightRail_NCE_MVP.kicad_sch
2. Schematic editor opens
3. Navigate and review:
   • Power management (left side)
   • FPGA & decoupling (center)
   • Optical interface (right side)
   • Thermal management (bottom)
4. Run ERC: Tools → Electrical Rules Checker
5. Should show: ✓ No errors

STEP 5: COMPLETE PCB LAYOUT (6-12 hours)
────────────────────────────────────────────────────────────────────────────────
1. Read: KICAD_DESIGN_GUIDE.txt (Section 5: PCB Layout Best Practices)
2. Follow these steps:
   a) Create board outline (200mm × 150mm)
   b) Place components (power, FPGA, optical sections)
   c) Route power distribution (5V, 1.8V, 3.3V, 12V)
   d) Route signal traces (JTAG, USB, optical)
   e) Add thermal vias (0.3mm × 120 under FPGA)
   f) Verify with DRC (Design Rule Check)
3. Save: File → Save (Ctrl+S)

STEP 6: GENERATE MANUFACTURING FILES (1 hour)
────────────────────────────────────────────────────────────────────────────────
1. Gerber files:    PCB → File → Plot
2. Drill files:     PCB → File → Fabrication Outputs
3. BOM:             Schematic → Tools → Generate BOM
4. Pick & Place:    PCB → File → Fabrication Outputs
5. Organize in Manufacturing folder
6. Submit to PCB fab (PCBWay, JLCPCB, etc)

STEP 7: ORDER COMPONENTS & MANUFACTURE (4-6 weeks)
────────────────────────────────────────────────────────────────────────────────
1. Order components using LIGHTRAIL_NCE_MVP_BOM.csv
2. Submit Gerber files to PCB manufacturer
3. Request SMD assembly quote
4. FPGA must be soldered manually (high cost, requires rework station)
5. PCBs arrive in 7-14 days
6. Assembly takes another 1-2 weeks

TOTAL PROJECT TIMELINE:
   Installation: 0.5 hour

   PCB layout: 8 hours (average)
   File generation: 1 hour
   Component ordering: 0.5 hour

💡 DESIGN HIGHLIGHTS
════════════════════════════════════════════════════════════════════════════════

WHAT MAKES THIS DESIGN SPECIAL:

✨ Thermal Management
   • Copper-Invar baseplate for heat spreading
   • Thermal vias (0.3mm × 120 array) for die cooling
   • Validated to keep FPGA <75°C at 50°C ambient
   • Optional 40mm fan for extra cooling margin

✨ Optical Interface
   • 8 independent spiking neuron channels
   • Transimpedance amplifier (TIA) for optical input
   • Modulator driver for optical output
   • 1 GHz bandwidth (future-proof for higher data rates)

✨ Power Management
   • 100W USB Power Delivery capable
   • Multiple isolated voltage rails (1.8V, 3.3V, 12V)
   • Soft-start and inrush current protection
   • Comprehensive decoupling & filtering

✨ FPGA Implementation
   • Xilinx Kintex-7 with 420K logic cells
   • 8 leaky integrate-and-fire neurons (VHDL)
   • Configurable thresholds & refractory periods
   • 250 MHz internal clock
   • BGA escape routing for tight pitch

3. LEMO FIBER CONNECTORS
   • Lead time: 4 weeks
   • Cost: $50 per connector (×2 per unit = $100/unit)
   • Note: Precision alignment required

Plan accordingly! FPGA lead time is your critical constraint.

DESIGN LIMITATIONS:

1. Passive cooling only validated for continuous 5W load
   • Higher sustained loads may require fan
   • Thermal throttling available as safety mechanism

2. Optical interface requires external laser source
   • Not included in this design (laser specification separate)
   • Fiber connectors provided (MPO-8 standard)

3. PCB density is high (250+ components, 4-layer)
   • Requires professional assembly for BGA components
   • Manual solder-and-rework not feasible
   • Budget assembly costs accordingly
