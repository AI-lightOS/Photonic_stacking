2. PROJECT STRUCTURE OVERVIEW
===========================================

UNDERSTANDING THE KICAD PROJECT

The project consists of multiple files that work together:

1. .kicad_pro (Project File)
   ├─ Stores project settings
   ├─ Defines design rules (trace width, clearance, etc)
   ├─ Tracks library paths
   ├─ Records board dimensions and constraints
   └─ Format: JSON (human-readable text)

2. .kicad_sch (Schematic File)
   ├─ Contains circuit diagram
   ├─ Lists all components and connections
   ├─ Stores hierarchical structure (if multi-sheet)
   ├─ Defines nets (electrical connections)
   └─ Format: S-expression (KiCAD native)

3. .kicad_pcb (PCB Layout File)
   ├─ Physical board layout
   ├─ Trace routing (copper on layers)
   ├─ Via placement and types
   ├─ Pad definitions (solder pads)
   ├─ Board outline and mechanical layers
   └─ Format: S-expression

4. Symbol Libraries (.kicad_sym)
   ├─ Component symbols for schematics
   ├─ Stores: pins, labels, outline, reference/value fields
   ├─ Example: Xilinx_Kintex7.kicad_sym → XC7K420T symbol
   └─ Reusable across projects

5. Footprint Libraries (.kicad_mod)
   ├─ Physical component packages
   ├─ Stores: pad locations, pad size, silkscreen
   ├─ Example: BGA676_Kintex7.kicad_mod → 27×27mm BGA footprint
   └─ Linked to symbols via "footprint" field

PROJECT WORKFLOW
────────────────

Stage 1: SCHEMATIC DESIGN
  ├─ Add components to schematic
  ├─ Draw connections (nets)
  ├─ Assign footprints to each component
  ├─ Check electrical rules (ERC)
  └─ Annotate (assign reference numbers: U1, R1, C1, etc)

Stage 2: PCB LAYOUT
  ├─ Create board outline (dimensions, keepout areas)
  ├─ Place components on board
  ├─ Route copper traces to connect nets
  ├─ Add vias for multi-layer connections
  ├─ Check design rules (DRC)
  └─ Add silkscreen text and graphics

Stage 3: MANUFACTURING
  ├─ Generate Gerber files (copper layers, masks, silkscreen)
  ├─ Generate drill file (for via/hole drilling)
  ├─ Generate BOM (Bill of Materials)
  ├─ Export pick & place file (for assembly partner)
  └─ Review files for manufacturability (DFM)

HOW TO ADD COMPONENTS
──────────────────────

Method 1: Use the "Add Component" Tool
1. In schematic editor: Shift+A (or Place → Add Symbol)
2. Symbol selector dialog opens
3. Type component name in search box:
   - "C" for capacitor
   - "R" for resistor
   - "L" for inductor
   - "USB_C" for USB connector
   - "XC7K420T" for FPGA
4. Select from list
5. Click cursor on schematic to place

Method 2: Keyboard Shortcuts
- A → Add symbol (search by name)
- W → Add wire (connect components)
- U → Add unconnected power pins
- V → Add via (on PCB layer)
- D → Delete component/wire

EXAMPLE: Adding the FPGA (U1)
────────────────────────────

1. Press Shift+A
2. Search: "XC7K420T" (or "Xilinx_Kintex7_BGA676")
3. Click result to select
4. Place on left-center of schematic
5. Press Escape to finish placement
6. Right-click on FPGA → Edit Symbol Properties
7. Set reference: U1
8. Set footprint: "BGA676_Kintex7" (links to physical package)
9. Press Enter to confirm

STEP 3.3: Connect Components with Wires
─────────────────────────────────────────

After placing components, you draw electrical connections:

1. Press W (or click Wire tool)
2. Click on a pin (red dot appears)
3. Move cursor to second pin and click
4. KiCAD draws a wire between pins
5. Press Escape to stop drawing

Wire Color Meaning:
  • White wire:   Normal (unconnected or warning)
  • Green wire:   Connected (valid net)
  • Red wire:     Conflict/short-circuit
  • Blue wire:    New (but valid) net

CRITICAL CONNECTIONS FOR LIGHTRAIL MVP
───────────────────────────────────────

Power Rails (Must connect to all decoupling capacitors):
  USB 5V → TPS65250 VOUT → Buck converter inputs
  Buck outputs → FPGA power pins + Decoupling caps (critical!)
  
  VCC_CORE_1.8V → FPGA core pins (many)
  VCC_IO_3.3V → FPGA I/O pins + TIA + Modulator
  GND → FPGA pins + all return paths (via ground planes)

JTAG Programming (for downloading bitstream):
  TMS (Test Mode Select) → FPGA pin AA11
  TDI (Test Data In) → FPGA pin Y17
  TDO (Test Data Out) → FPGA pin V15
  TCK (Test Clock) → FPGA pin W15
  GND → FPGA pins (any GND)
  
  Pull-ups: TMS 4.7k to VCC_IO, TDI 4.7k to VCC_IO

Optical Interface:
  TIA Output (analog) → FPGA ADC input (specific pin, check datasheet)
  FPGA GPIO (digital out) → Modulator driver input
  FPGA GPIO (PWM) → Fan control via MOSFET

Thermal Sensor:
  TMP36 output (analog) → FPGA ADC input
  TMP36 GND → Global GND
  TMP36 +3.3V → VCC_IO

STEP 3.4: Add Net Labels (Optional but Recommended)
────────────────────────────────────────────────────

Instead of drawing long wires across the schematic, use labels:

1. Place label: Ctrl+J or Place → Add Label
2. Click on schematic
3. Type label name: "VCC_CORE_1.8V"
4. Connect to net with short wire
5. Repeat elsewhere with same label → automatically connected!

Benefits:
  • Cleaner, easier-to-read schematic
  • No long wires cluttering the diagram
  • Global labels automatically link across sheets

STEP 3.5: Assign Footprints (Critical!)
─────────────────────────────────────

Every schematic component must have a footprint (physical package):

1. Schematic editor: Tools → Assign Footprints (or press E)
2. Panel opens on right showing all components without footprints
3. For each component:
   a. Click in "Footprint" column
   b. Footprint selector dialog opens
   c. Type package size: "0603" (resistor), "1210" (capacitor), "BGA676" (FPGA)
   d. Select from list
   e. Confirm with Enter

Common Package Sizes:
  Resistor/Capacitor:
    • 0402: Tiny (1mm × 0.5mm) - hard to hand-solder
    • 0603: Standard small (1.6mm × 0.8mm)
    • 0805: Larger (2mm × 1.25mm) - easier to solder
    • 1206: Large (3.2mm × 1.6mm) - for high-power
    • 1210: Extra-large (3.2mm × 2.5mm) - for high-value capacitors

  IC Packages:
    • SOIC8: Small outline (8 pins, 4mm wide)
    • SOIC20: Medium (20 pins)
    • LQFP48: Quad flat-pack (48 pins)
    • BGA: Ball grid array (many pins in 2D array)
      - BGA676: 27×27mm array (Xilinx Kintex-7)

  Connectors:
    • 0.1" Header: Standard pitch (2.54mm)
    • USB-C: 24-pin surface-mount
    • Lemo 00: Precision fiber connector

STEP 3.6: Run Electrical Rules Check (ERC)
──────────────────────────────────────────

Before moving to PCB layout, verify your schematic:

1. Schematic editor: Tools → Electrical Rules Checker (or press Ctrl+Shift+V)
2. Check dialog runs and shows errors/warnings:
   • Red icon: ERROR - must fix (floating pin, open net)
   • Yellow icon: WARNING - usually OK (power on output pin, etc)

Fix Common Errors:
  ✗ "Pin not connected": Wire not properly connected to pin
  ✗ "Floating pin": Pin with no net label or wire
  ✗ "Duplicate component reference": Two U1's or R1's
  ✓ "Power on output pin": Often OK for power supplies

STEP 5.3: Critical Trace Routing Rules
───────────────────────────────────────

Power Distribution (Ground & Supply):

1. Ground Plane (Layer 2: Bottom Copper):
   • Unbroken copper sheet connecting all GND pins
   • Multiple vias (every 2-3mm) tie top components to ground plane
   • Minimize loop area (ground return path close to signal trace)

2. Power Planes (or power distribution traces):
   • VCC_CORE_1.8V: Thicker traces (20-25 mil = 0.5mm)
   • VCC_IO_3.3V: Medium traces (15 mil = 0.4mm)
   • USB 5V input: Extra thick (30 mil = 0.75mm)
   • Separate planes for each voltage (avoid ground bounce)

3. Via Strategy:
   • One via every 2-3mm on power distribution
   • Multiple vias (2-4) on net transitions
   • Thermal vias under FPGA (0.3mm, 120× array at 2mm pitch)
   • Via stitching around high-speed signals (every 1mm)

Signal Routing (JTAG, USB):

1. JTAG traces (slow, ~1MHz):
   • Trace width: 8 mil (0.2mm) minimum
   • Length matching: Not critical (< 10cm total)
   • Impedance: Not critical for JTAG

2. USB traces (high-speed, 480 Mbps):
   • D+/D- traces: Differential pair, 90Ω impedance
   • Trace width: 8-10 mil (0.2-0.25mm)
   • Separation: Keep constant (~8 mil)
   • Length matching: ±3mm (not critical at 480 Mbps but good practice)
   • Shielding: Ground pours around differential pair

3. Optical Interface (analog, sensitive):
   • TIA input (from photodiode): Shielded
   • TIA output: Twisted pair if possible
   • Modulator driver output: Shielded from noise
   • Keep away from FPGA switching noise (digital lines)
   • Ground pour underneath analog traces (shield)

4. Temperature Sensor (analog):
   • Separate from digital/switching signals
   • Shielded trace if > 10cm long
   • Bypass capacitor close to sensor GND

STEP 5.4: Thermal Management Layout
────────────────────────────────────

Critical for keeping FPGA <75°C:

1. Thermal Vias Under FPGA:
   • Array of 0.3mm vias under die
   • Pitch: 2mm hexagonal pattern
   • Connect to internal copper baseplate (above ground plane)
   • Ground plane (Layer 2) provides heat sink

2. Copper-Invar Baseplate:
   • Mounted directly above FPGA BGA pads (soldered)
   • 120×100mm footprint (covers die)
   • 2mm thickness: 1mm copper (top) + 1mm Invar (bottom)
   • Copper thermal conductivity: 385 W/m·K
   • Soldered via wave-solder process (high temp, 260°C)

3. Air Flow Considerations:
   • Place fan exhaust vents on enclosure sides
   • Keep ventilation area free of tall components
   • Don't block thermal vias with adjacent components
   • Temperature sensor close to FPGA (within 5cm)

STEP 5.5: Layer Stackup Design
─────────────────────────────

Standard 4-layer PCB (cheapest for high-density):

```
Layer 1 (F.Cu - Front Copper):
  ├─ FPGA BGA pads
  ├─ Thermal vias array (under FPGA)
  ├─ Signal traces for external components
  └─ Copper baseplate landing pads

Layer 2 (GND - Ground Plane):
  ├─ Continuous ground copper sheet
  ├─ Lowest impedance return path
  └─ Heat sink for thermal vias

Layer 3 (Internal Power):
  ├─ VCC_CORE_1.8V plane (split from Layer 4)
  ├─ VCC_IO_3.3V plane
  └─ VCC_FAN_12V (narrow distribution)

Layer 4 (B.Cu - Back Copper):
  ├─ Component pads (soldered side)
  ├─ Power distribution traces
  ├─ Ground return traces
  └─ stitching vias
```

Design Rules (in KiCAD):
1. File → Board Setup → Design Rules
2. Copper tab:
   - Trace width: 0.2mm minimum
   - Trace spacing: 0.15mm minimum
   - Via diameter: 0.4mm (pad) + 0.2mm (hole)
   - Via spacing: 0.3mm minimum

3. Layers tab:
   - Verify 4 layers selected
   - Copper weight: 1oz/1oz (35µm standard)

STEP 5.6: Place Components in PCB Editor
─────────────────────────────────────────

1. PCB editor: Ctrl+Shift+U (or Tools → Update PCB from Schematic)
2. Ratsnest dialog: Click "Update PCB" → Components appear (scattered)
3. Move components:
   - Click component to select
   - Drag to position on board
   - Rotate with R key
   - Fine-tune with arrow keys

Placement Order:
1. FPGA (U1) - largest, most pins, center of board
2. Power management (buck converters, capacitors) - near USB
3. Optical components (TIA, modulator drivers) - one side each
4. Connector area (USB-C, JTAG headers) - edges

STEP 5.7: Route Traces (Copper Layer)
──────────────────────────────────────

After component placement, draw copper traces to connect nets:

1. PCB editor: X key (or Route → Route Traces)
2. Click on start pad → Move cursor → Click on end pad
3. KiCAD auto-routes optimally (usually)
4. Manual routing for tight areas:
   - Press V to add via (switch to different layer)
   - Use arrow keys to step trace
   - Press Escape to finish trace

Auto-routing (less manual work):
1. PCB editor: Tools → Auto-router
2. Click "Start" → KiCAD routes all remaining traces
3. Usually 80-95% success rate

Manual touch-ups:
  • Fix any design rule violations (shown in red)
  • Separate power/ground traces to avoid interference
  • Add guard traces around analog signals

STEP 5.8: Add Via Stitching & Thermal Relief
──────────────────────────────────────────────

1. Via stitching (for signal integrity):
   - Around high-speed traces (USB D+/D-)
   - Around analog signals (TIA, modulator feedback)
   - Every 1-2mm spacing

2. Thermal relief pads:
   - On power/ground pads connected to planes
   - Reduces heat loss during soldering (pads don't wick heat)
   - Add spoke pattern (4× spokes, 0.3mm width)
   - KiCAD: Select pad → Properties → Thermal relief type

STEP 5.9: Add Silkscreen (Top Layer Text)
──────────────────────────────────────────

1. PCB editor: Select "F.SilkS" layer (Front Silkscreen)
2. Add text:
   - Ctrl+Shift+T (or Place → Add Text)
   - Enter text (component reference: "U1", "C1")
   - Size: 3mm text (readable on small components)

3. Add graphics:
   - "+" marks for alignment (placement guide)
   - Arrows indicating orientation
   - Board outline on silkscreen (for clarity)

STEP 5.10: Design Rule Check (DRC)
────────────────────────────────────

Before manufacturing, verify all design rules:

1. PCB editor: Tools → Design Rules Check (or Ctrl+Shift+B)
2. DRC runs and reports:
   ✓ No copper-to-copper shorts
   ✓ Minimum trace width
   ✓ Minimum clearance (0.15mm)
   ✓ Via holes not in pads
   ✓ All nets routed (no floating references)

3. Common DRC errors & fixes:
   ✗ "Copper-to-copper short": Two nets touching → reroute trace
   ✗ "Via under pad": Via placed where component pad is → move via
   ✗ "Unconnected net": Segment not routed → add trace
   ✗ "Trace too narrow": Reduce trace length or add copper → widen trace

STEP 5.11: 3D Visualization (Sanity Check)
───────────────────────────────────────────

1. PCB editor: View → 3D Viewer (or Alt+3)
2. 3D board opens showing:
   - Component footprints (copper pads)
   - Mounted components (if 3D models available)
   - Enclosure outline (if imported)
   - Helps verify no components interfere

STEP 5.12: Save PCB Layout
────────────────────────────

File → Save (Ctrl+S)
The PCB file is now complete: LightRail_NCE_MVP.kicad_pcb

7. TROUBLESHOOTING & COMMON ISSUES
===========================================

"Symbol not found" error:
→ Check symbol library path (Preferences → Manage Libraries)
→ Verify library .kicad_sym file exists
→ Re-add library if missing

Cannot find footprint:
→ Search footprint library for similar package
→ Manually create footprint if missing
→ Use standard library footprints when possible

DRC errors after layout:
→ Common: Trace spacing too tight
→ Solution: Reroute net or widen trace
→ Tool: Tools → Design Rules Check → Details button

"Floating net" warning:
→ Some part of your circuit is not connected
→ Tool: PCB editor → Tools → Unconnected Items (highlights in color)

Gerber file verification:
→ Download free Gerber viewer: ViewPlot, GerberLogix
→ Open .gbr files to visualize layers before manufacturing
→ Check for bridges, shorts, missing features
