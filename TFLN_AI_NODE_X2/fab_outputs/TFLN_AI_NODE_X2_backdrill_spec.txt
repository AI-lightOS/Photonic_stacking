===============================================================
TFLN_AI_NODE_X2 - BACK-DRILL SPECIFICATION
===============================================================
Date: 2026-04-12
Board: TFLN_AI_NODE_X2
Layers: 22 (F.Cu to B.Cu)
Thickness: 3.2mm

===============================================================
PURPOSE
===============================================================
Back-drilling removes via stubs that cause impedance
discontinuities and resonances at high frequencies.
Required for PCIe Gen6 (64 GT/s) and DDR5-4800 signals.

===============================================================
BACK-DRILL ZONE 1: 85-OHM PCIe / SerDes VIAS
===============================================================
Target Impedance:  85 ohm differential
Via Drill:         0.25mm (T02 in PTH drill file)
Via Pad:           0.50mm
Anti-pad:          0.80mm
Signal Layers:     L4 (In3.Cu)
Reference Layers:  L3 (In2.Cu GND), L5 (In4.Cu GND)

Back-Drill Direction: FROM BOTTOM (B.Cu side)
Drill-back to:        L5 (In4.Cu) + 100um clearance
Remaining stub:       < 5 mil (127 um)
Tolerance:            +/- 100 um

Affected Nets:
  - PCIe_TX_J*_*_P/N (all PCIe transmit pairs)
  - PCIe_RX_J*_*_N/P (all PCIe receive pairs)
  - SERDES_U1_U2_*_P/N (inter-die SerDes)
  - NVME_TX_J*_*_P/N (NVMe transmit)
  - NVME_RX_J*_*_P/N (NVMe receive)

Estimated Via Count: ~500 vias

Identification:
  - Marked on User.1 layer in KiCad
  - Yellow annotation zone on PCB
  - All vias with T02 drill connecting to In3.Cu nets

===============================================================
BACK-DRILL ZONE 2: 100-OHM TFLN RF VIAS
===============================================================
Target Impedance:  100 ohm differential
Via Drill:         0.25mm (T02 in PTH drill file)
Via Pad:           0.50mm
Anti-pad:          1.00mm (larger for 100-ohm)
Signal Layers:     L1 (F.Cu) ONLY
Reference Layers:  L2 (In1.Cu GND)

NOTE: TFLN RF signals should NOT use vias.
      These are routed on L1 (F.Cu) only.
      Back-drill applies to any unavoidable
      transition vias at the BGA breakout.

Back-Drill Direction: FROM BOTTOM (B.Cu side)
Drill-back to:        L2 (In1.Cu) + 100um clearance
Remaining stub:       < 3 mil (76 um)
Tolerance:            +/- 50 um (tighter for 100 GHz)

Affected Nets:
  - TFLN_RF_U3_CH*_P/N (if via transitions exist)
  - TFLN_RF_U4_CH*_P/N (if via transitions exist)

Estimated Via Count: ~32 vias (BGA breakout only)

Identification:
  - Marked on User.1 layer in KiCad
  - Orange annotation zone on PCB

===============================================================
BACK-DRILL ZONE 3: DDR5 SIGNAL VIAS
===============================================================
Target Impedance:  80 ohm differential (DQS), 40 ohm SE (DQ)
Via Drill:         0.25mm (T02 in PTH drill file)
Via Pad:           0.50mm
Anti-pad:          0.80mm
Signal Layers:     L6 (In5.Cu), L16 (In15.Cu)
Reference Layers:  L5/L7 (GND/Power), L15/L17 (Power/GND)

Back-Drill Direction: BOTH SIDES
  Top drill:  From F.Cu to L6 + 100um
  Bottom drill: From B.Cu to L16 + 100um
Remaining stub:       < 8 mil (203 um)
Tolerance:            +/- 100 um

Affected Nets:
  - DDR5_DQ_J*_* (data lines)
  - DDR5_DQS_J*_*_P/N (strobe pairs)
  - DDR5_CA_J*_* (command/address)
  - DDR5_CK_J*_P/N (clock pairs)

Estimated Via Count: ~1200 vias

Identification:
  - Marked on User.1 layer in KiCad
  - Cyan annotation zone on PCB

===============================================================
INSPECTION REQUIREMENTS
===============================================================
1. Cross-section 3 representative vias per zone
2. Measure remaining stub length
3. Verify no damage to target signal layer
4. Check copper plating integrity after drilling
5. TDR measurement on test coupons

===============================================================
NOTES
===============================================================
- All back-drill holes must be plugged with non-conductive fill
- Back-drill diameter = original drill + 0.20mm (0.45mm total)
- Minimum copper clearance from back-drill: 0.15mm
- Do NOT back-drill power/ground vias
- Do NOT back-drill mounting holes
